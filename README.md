# IML Paintability Winning and Losing States

## Introduction
This project is a part of the IML Paintability project, which explores the online-coloring of multi-partite graphs.
This repository stores winning and losing states (for definition of winning and losing states, see the research paper at [https://arxiv.org/abs/2411.19462](https://arxiv.org/abs/2411.19462)).

## Results
Here are the results that can be verified:

| $k \times n$              | Paintability |
|---------------------------|--------------|
| $3 \times 4$              | 5            |
| $3 \times 5$              | 7            |
| $2 \times 3,\ 3 \times 3$ | 7            |
| $2 \times 2,\ 3 \times 4$ | 7            |
| $2 \times 1,\ 3 \times 5$ | 8            |
| $3 \times 6$              | 8            |
